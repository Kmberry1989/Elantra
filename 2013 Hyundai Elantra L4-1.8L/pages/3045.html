Mode Control Actuator





Description

The mode control actuator is located at the heater unit.
It adjusts position of mode door by operating mode control actuator based on signal of A/C control unit. Pressing mode select switch makes the mode control actuator shift in order of vent-> B/L -> floor -> mix.
