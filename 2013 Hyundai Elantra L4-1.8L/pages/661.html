Seat Belt Switch





Description

Via the seat belt/Door switch, the ISG function can detect that the driver has fastened the seat belt/door. If the driver has not fastened the seat belt/door, the ISG function reacts as follows. If the seat belt or door is opened, the engine must not be started or stopped by the ISG function for safety reasons.
