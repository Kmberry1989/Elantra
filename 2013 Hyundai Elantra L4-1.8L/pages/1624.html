Wheel Stud / Lug Nut: Specifications





Hub Nut Tightening Sequence

Tighten the hub nuts as follows.

Tightening torque : 88.3 - 107.9N.m (9.0 - 11.0kgf.m, 65.1 - 79.6lb-ft)






CAUTION: When using an impact gun, final tightening torque should be checked using a torque wrench.
